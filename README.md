# OMNI-SYSTEM

### ⚡ Unified, Extensible Dashboard for Human-Machine Experimentation

**OMNI-SYSTEM** is a cyber-futurist, extensible dashboard for memory, creativity, gaming, metacognition, and more. Inspired by immersive UIs and the ambition to reimagine what personal digital systems can do.

---

## 🚀 Features

- **Session Vault:** Track sessions, coins, and achievements.
- **Omni-Protocol:** Advanced linguistic profiling/categorization of ideas.
- **Task Manager:** Built-in Omnitasks for to-dos and productivity.
- **Tactical Console:** System & gateway state, memory timeline, logs.
- **NEXUS Jukebox:** Generate (or simulate) DnB/Techno tracks – with achievement rewards.
- **Card Effects Builder:** Live, animated card rendering with creative controls.
- **Vault Actions:** Memories, coins, and resets, plus frequency/mode control.
- **User Profile:** Persistent XP, level, and future avatar customization.
- **Plugin/Extension System (extensible stub):** Community plugins and UI integrations—*expand into anything!*
- **Cloud Sync / Export (planned):** Save/restore state, cloud integration.

## 🛠️ Getting Started

Clone & open `/src/index.html` – all state persists in-browser (localStorage).  
No backend by default; pure HTML/CSS/JS, modular and hackable!

```bash
git clone https://github.com/Dublin7/omni-system.git
cd omni-system/src
open index.html   # or use your favorite web server/live-server
```
