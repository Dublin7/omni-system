# Plugin/Extension System

This folder is the starting point for **OMNI-SYSTEM plugins**.

Plugins can:
- Add cards, controls, or new panels
- Hook into memory/tasks/events
- Extend dashboard logic via JS (API coming soon)

**Share your ideas for the plugin API in Issues!**  
Coming soon: API, loader, sample plugins.

---

- To develop: Place plugin sample files here.
- To propose a plugin: Open an Issue with `[Plugin Proposal]` in the title.

Let’s make OMNI-SYSTEM endlessly extensible!
